# HANDOFF — Пакет 01: Налаштування розкладено на вкладки

База: `cbe9ed8` (гілка `stage2-supabase`, чистий статус перед стартом).
Код: `86824f0`. Фінальний стан (цей HANDOFF): `62325cd`.

## Що зроблено

Сторінка `/settings` розкладена на 4 вкладки без зміни моделі даних,
сховища, експорту/імпорту й доменних дій:

- **Фінанси** — валюта відображення + редактор курсів (ті самі дії
  `setDisplayCurrency` / `saveRates`, що й на сторінці Фінанси;
  гарантія «курси не скидають валюту» збережена).
- **AI-помічник** — той самий `ProviderSettingsCard`, що й на
  `/assistant` (сховище `crm_assistant_provider`, ключі ніде не зберігаються).
- **Копії та імпорт** — експорт/імпорт/відновлення/інцидент/попередження,
  уся логіка лишилася на сторінці й передається пропсами.
- **Система** — стан збереження, лічильники, пошкоджені колекції, журнал
  (очищення журналу як і раніше не чіпає здоров'я даних).

Додано централізований реєстр `lib/settings-tabs.ts`, щоб пакети 04
(хостинг) і 05 (завдання/нагадування) додавали свої вкладки в одному місці
без паралельних правок сторінки. Активна вкладка переживає переходи
(`usePersistedState('settings:tab')`, sessionStorage — без секретів),
невідоме значення нормалізується до `finance`.

## Сценарії UI

- Десктоп 1440×900: вкладки в один ряд, картки 2 колонки (чинний
  `.settings-grid` / `.tabs` без нових стилів).
- Мобайл 390×844: чинні стилі `.tabs`/`.tab` (full-width, min-height 44px)
  покривають 4 вкладки; секції складаються в 1 колонку через `.settings-grid`.
- Ручний клік-прохід у браузері **не виконувався** (немає доступу до
  інструмента браузера в цьому середовищі) — лише збірка + тести.
- Сценарії для основного агента: відкрити `/settings` → перемкнути 4 вкладки →
  змінити валюту на Фінанси → зберегти курси → перевірити, що сторінка Фінанси
  бачить ті самі значення; вкладка AI → змінити провайдера → перевірити, що
  `/assistant` бачить той самий; вкладка Копії → експорт JSON ідентичний
  старому; вкладка Система → лічильники/журнал як раніше; перезавантажити
  сторінку з невалідним `sessionStorage['crm:ui:settings:tab']` → впаде на `finance`.

## Що не перевірено

- Реальний iPhone / закрита CRM / production-доступ — не було.
- Ручний браузерний прохід (кліки, скріншоти) — не виконувався.
- Серверна частина/Supabase — пакет її не чіпає.

## Залишкові обмеження

- Дубль `COLLECTION_LABELS` між сторінкою (модалка імпорту) і секцією
  Системи — свідомо лишено, щоб не тягти спільний модуль у цьому пакеті;
  можна винести в пакеті 06 при узгодженні.
- `/assistant` лишає власну копію налаштувань провайдера (за ТЗ пакети не
  вимагають її прибирати; обидва місця пишуть в одне сховище).
- Редактор курсів на `/finance` не чіпався (єдине джерело дій спільне).
